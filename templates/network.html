4. End-to-End Protocol Stack Implementation
5-Layer Model

Protocol mapping across the 5 network layers, detailing each protocol's specific role in the hospital asset tracking architecture.

L5
Application Layer MQTT · HTTP/REST · HL7 FHIR
MQTT v3.1.1 publishes lightweight JSON telemetry. REST API delivers dashboard state. HL7 FHIR integrates with electronic health records.
L4
Transport Layer TCP (MQTT, HTTPS) · UDP (CoAP)
TCP provides 3-way handshake, connection-oriented byte stream, and guaranteed sequence delivery. Crucial for life-critical equipment tracking!
L3
Network Layer IPv4 / IPv6 · 6LoWPAN · ICMP
Hierarchical addressing with 10.20.0.0/22. Static DHCP reservations for BLE gateways. Inter-VLAN routing via Core L3 Switch.
L2
Data Link Layer IEEE 802.3 (Ethernet) · IEEE 802.15.1 (BLE)
Ethernet frames encapsulated with 802.1Q VLAN headers. Gateway converts BLE advertisement packets into Ethernet frames.
L1
Physical Layer 2.4 GHz ISM Band · Cat6 UTP (802.3af PoE)
BLE 5.0 beacons broadcast on channels 37, 38, 39. Ceiling gateways powered over Ethernet cables via 48V PoE switches.
Engineering Architecture Insight: Why MQTT uses TCP over UDP
MQTT runs on TCP (Port 1883 / 8883) because medical asset tracking requires lossless, ordered, and guaranteed delivery (QoS 1). If a ventilator is unplugged or wheeled past an exit door, a dropped UDP packet could allow equipment theft to go unnoticed!
5. Hospital Network Security & Privacy Architecture
WPA3 + TLS 1.3

Security mechanisms implemented to protect medical telemetry, prevent packet eavesdropping, and ensure compliance with healthcare cybersecurity standards.

WPA3-Enterprise & 802.1X / RADIUS Authentication
Gateways authenticate using EAP-TLS certificates via a central RADIUS server. Rogue access points and spoofed gateways are blocked at the switch port before receiving an IP address.
MQTT Payload Encryption via TLS 1.3 (Port 8883)
Telemetry payloads are encrypted using AES-256-GCM. Prevents man-in-the-middle sniffing of equipment locations and battery levels on the hospital LAN.
Zero Protected Health Information (PHI) on Radio Broadcasts
BLE tags broadcast ONLY an anonymous Tag ID (e.g. TAG-BLE-701) and RSSI. No patient names, diagnoses, or clinical telemetry are transmitted over the air.
Core Redundancy, QoS & Gateway Offline Buffering
Differentiated Services Code Point (DSCP EF / Expedited Forwarding) gives ventilator packets priority over guest Wi-Fi. If a switch port drops, gateways buffer up to 1,000 packets in flash memory until reconnected.
